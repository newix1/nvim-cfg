# Changelog ZeroVim

Все заметные изменения в конфигурации ZeroVim.

## [Unreleased]

### 🚀 Добавлено (Added)

- **Автоматическое восстановление позиции курсора**: при открытии файла курсор возвращается на последнюю позицию.
- **Подсветка висячих пробелов**: включается автоматически для файлов с кодом (работает от filetype, красный фон, как в VS Code).
- **Автосохранение**:
  - При потере фокуса окна (FocusLost).
  - При выходе из режима вставки (InsertLeave).
  - При переключении буфера (BufLeave).
- **Автоматическое чтение файлов**: при возврате фокуса в окно (FocusGained).
- **Новый бинд для смены рабочей директории**: `<leader>cd` меняет `cwd` на папку текущего файла.
- **Бинд для подсчёта плагинов**: `<leader>pc` показывает количество установленных плагинов.
- **Новые настройки опций**: `scrolloff`, `sidescrolloff`, `winborder`, `timeoutlen`.

### 🎨 UI/UX Изменения

- **Глобальные скруглённые рамки**: добавлена опция `winborder = 'rounded'` для всех плавающих окон (LSP, диагностика, командная строка).
- **Переработана система сообщений (`ui2`)**: все категории сообщений перенаправлены в отдельные окна.
  - Ввод команд (`typed_cmd`) теперь выводится в отдельное окно `msg`, что предотвращает перекрытие статусной строки.
  - Настроены высота и таймаут для сообщений (`msg.height = 0.3`, `timeout = 3000`).
- **Центрированная командная строка**: плагин `tiny-cmdline.nvim` переносит строку ввода команд в центр экрана (работает поверх `ui2`).

### 📦 Плагины

- **Добавлены новые плагины** (в модульную структуру `lua/plugins/`):
  - `blink.cmp` — сверхбыстрое автодополнение с Rust-бэкендом.
  - `codediff.nvim` — VSCode-подобный дифф с подсветкой по символам (бинды на `<leader>c`).
  - `diffview.nvim` _(отключен по умолчанию)_ — просмотр Git-диффов и истории (бинды на `<leader>g`).
  - `fzf-lua` _(отключен по умолчанию)_ — нечёткий поиск файлов, grep и многого другого.
  - `gitsigns.nvim` — визуальные индикаторы Git в редакторе.
  - `grug-far.nvim` — мощный поиск и замена по проекту (бинды на `<leader>s`).
  - `mini.indentscope` — визуализация отступов и подсветка текущей области.
  - `nvim-autopairs` — автоматическое закрытие скобок.
  - `nvim-treesitter` — улучшенная подсветка синтаксиса и навигация.
  - `oil.nvim` — редактирование файловой системы как обычного буфера.
  - `tiny-cmdline.nvim` — центрированная командная строка (работает поверх `ui2`).
  - `trouble.nvim` — удобный список диагностики, символов и ссылок (бинды на `<leader>x`).
  - `vim-illuminate` — подсветка всех вхождений слова под курсором.
  - `which-key.nvim` — подсказки по горячим клавишам.

- **Рефакторинг структуры плагинов**: все плагины вынесены в отдельные файлы в `lua/plugins/` и загружаются через `vim.pack`.

### 🗑️ Удалено (Removed)

- **Удалены устаревшие Git-бинды**: `gd`, `gf`, `gs`, `gg`, а также кастомный `git blame` через Diffview.
- **Удалены LSP-бинды**: `rn`, `gr`, диагностические бинды `cd`, `]d`, `[d`, `]e`, `[e`, `]w`, `[w`.
- **Удалены плагины** из `plugins.lua`:
  `web-devicons`, `lualine`, `base16-nvim`,
  `gitsigns`, `neogit`, `diffview`, `codediff`,
  `gitlineage`, `tig-explorer`, `bclose`, `fzf-lua`,
  `treesitter`, `blink.cmp` (все перенесены в модульную структуру `plugins/`).
- **Удалён файл `some.txt`**.

### ♻️ Изменено (Changed)

- **Рефакторинг конфига**: `init.lua` теперь загружает модули из `lua/config.lua`, `lua/keymap.lua` и `lua/plugins/init.lua`.
- **Обновлены настройки `fillchars`**: изменён формат для лучшей совместимости.
- **Включены относительные номера строк** (`relativenumber`).
